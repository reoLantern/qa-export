# qa-export

问答原文已经在本地会话记录里。**不要自己复述重写**——既费上下文又会走样。
一律调用本 SKILL.md 同目录下的 `scripts/qa_export.py`（下称 `$SCRIPT`）。

## 默认流程：两条命令

先空跑确认选中的轮次（输出只有每轮一行）：

```bash
python3 "$SCRIPT" -n 2 --dry-run -o QA.md
```

列出来的轮次和用户说的对得上，就去掉 `--dry-run` 再跑一次，完成。

**不要为了「先看看情况」去跑 `-l`**——那会把整个会话的提问列表读进上下文。
只有在空跑的结果对不上时才需要它。

## 把用户的话翻译成参数

| 用户说 | 命令 |
| --- | --- |
| 「刚才这轮」「最后一轮」 | `-n 1` |
| 「刚才那两轮」「最近 3 轮」 | `-n 2` / `-n 3` |
| 「第 3 轮」「第 5 到 7 轮」 | `-t 3` / `-t 5-7` |
| 指某个更早的话题，但没说第几轮 | `-l --tail 20` 找到序号，再用 `-t` |
| 「整个会话」 | `-t 1-<总轮数>`（总轮数在空跑输出里） |

`-n` **已经自动排除用户刚发出的这条请求**（当前这一轮还没结束）。
不要为此手动 +1 补偿，那样反而会错位。

用户没说存哪里就用 `QA.md`（`-o` 是追加，文件不存在会自动建）。
没说要哪几轮就问一句，不要猜。

## 其他选项

| 选项 | 作用 |
| --- | --- |
| `--sessions` | 列出当前目录下的会话（Claude Code 和 Codex 都扫） |
| `-s ID` | 指定会话：id 前缀，或 Claude Code 的会话名（会自动切到该会话的目录） |
| `-a claude\|codex` | 指定读哪个 agent 的记录，默认自动判断 |
| `-C DIR` | 指定项目目录，默认当前目录 |
| `--no-answer` | 只导出提问 |
| `--sidechain` | 连子 agent 的对话一起导出 |
| `--all-branches` | 保留被改写重发时废弃的旧提问 |
| `--include-pending` | 不排除当前进行中的那一轮 |

## 报告方式

导出完只说写了哪几轮、写进了哪个文件，**不要把问答内容复述一遍**。

可以顺带提一次：用户自己在输入框敲 `! python3 "$SCRIPT" -n 1 -o QA.md`
（或装好的 `qa` 命令）是零 token 的，完全不经过模型。

## 一个时序前提

某一轮的回答要等它生成完才落盘。所以「导出刚刚这一轮」只能在那一轮结束之后跑；
`-n` 的自动排除处理的正是这件事。
